# Quantum Computing Advances and Hardware Review (2025)
**Source ID:** QUANTUM-2025

## 1. Surface Code Scaling
Rotated Surface Codes require d^2 physical data qubits and d^2 - 1 ancillary measurement qubits for code distance d (e.g., d=3 requires 17 physical qubits; d=7 requires 97 physical qubits).
Below the physical threshold error rate of ~1.0%, increasing code distance exponentially suppresses logical error rates by 10x per step increase in d.

## 2. Neutral Atoms vs Superconducting Transmons
Key hardware architectures:
1. Neutral Atom Optical Tweezers: Suspension of Rubidium-87 or Ytterbium-171 atoms in laser tweezer arrays. Advantages include all-to-all connectivity via dynamic shuttle movement, coherence times exceeding 10 seconds, and 99.5% Rydberg entangling gate fidelity.
2. Superconducting Transmon Processors: Offer fast gate execution (10-30 nanoseconds per gate) but suffer from fixed planar nearest-neighbor coupling and dilution refrigerator loss.

## 3. Nitrogenase Chemistry Simulation
A 48-logical-qubit neutral-atom system calculated the catalytic nitrogenase FeMoco cluster ground state energy to within 1.2 kcal/mol accuracy in 28 minutes, compared to 45 days of classical supercomputing compute.
